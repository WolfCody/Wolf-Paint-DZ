## Operational reference: committing generated bootstrap files (historical, done in 35412ef)
If `gradlew` or `Cargo.lock` ever have to be regenerated (for example after changing the Gradle version): run the workflow, download the artifact `bootstrap-files`, unpack it into the repository root, `chmod +x gradlew`, then
```bash
git add Cargo.lock gradlew gradlew.bat gradle/wrapper/gradle-wrapper.jar
git update-index --chmod=+x gradlew
git ls-files -s gradlew        # mode must be 100755
```
or use `scripts/generate-wrapper.sh` locally. Do not edit `gradle-wrapper.properties` by hand. Optional hardening: add `distributionSha256Sum` from gradle.org/release-checksums.
